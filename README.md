# US Elections Forecast

Predicting House and Senate outcomes for the 2026 US midterm elections.

## Data

Data is not included in this repo. Download the following file and place it in the `data/` folder:

**MIT Election Data and Science Lab — U.S. House 1976–2024**
https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/IG0UN2

Download `1976-2024-house.tab` from that page.
