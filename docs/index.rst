US House 2026 Election Forecast
================================

Predicts 2026 US House election outcomes district-by-district using a stacking ensemble
(Logistic Regression + LightGBM + Random Forest) with Monte Carlo simulation for seat-count
uncertainty. See the project's top-level ``README.md`` for setup and data-fetching
instructions.
